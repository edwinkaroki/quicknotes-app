# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organize, search, and delete notes. Notes can be grouped into Personal, Work, or Study categories, and they are saved in the browser so they remain available after refreshing the page.

## Features

- Add notes with different categories
- Validate notes before adding them
- Limit notes to 200 characters
- Display the date and time a note was created
- Delete individual notes
- Display the number of notes
- Search notes as you type
- Save notes using localStorage
- Responsive layout for smaller screens

## How to Run Locally

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional software or dependencies are required.
